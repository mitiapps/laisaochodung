# Map data licence (ODbL 1.0)

Maps derived from OpenStreetMap contain information from OpenStreetMap, which is made available
under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

These files form a derived database and are licensed under the ODbL 1.0, separately from the
Apache-2.0 code of this repository:

- the raw extracts, `data/maps/<id>/raw.overpass.json`, of every map with `kind: osm`;
- the overrides and source files of those maps, `data/maps/<id>/overrides.yaml` and
  `data/maps/<id>/source.yaml`;
- the built JSON of those maps, `public/maps/<id>.json`, generated by `npm run build:maps`.

Share-alike applies to the data only; it does not reach the code. The game shows the attribution
"© OpenStreetMap contributors, ODbL" with every OSM-derived map.

Tutorial maps (`kind: tutorial`) are drawn by hand for this project, contain no OpenStreetMap data
and are covered by the repository's Apache-2.0 licence.
